title: Learner Profiles
---

## Sam, new to the command line

Sam is a postdoc who works mostly in GUI tools and has never installed a
command line program. Sam needs the setup instructions to say exactly which
terminal application to open and what success looks like.

## Alex, experienced but restricted

Alex writes Python daily but works on a managed laptop without administrator
rights. Alex needs to know that `uv` installs into the user's home directory
and does not require elevated privileges.
